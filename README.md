# OmniScanner v1.4 "Multimedia Edition" 🚀
### Inteligentny system audytu danych i deduplikacji wideo/foto

**OmniScanner** to zaawansowane narzędzie do zarządzania zasobami cyfrowymi. Wersja 1.4 wprowadza pełne wsparcie dla formatów wideo, co czyni go idealnym narzędziem do czyszczenia dysków z ciężkich nagrań 4K, dubli filmowych i starych archiwów mobilnych.

## 🌟 Nowości w wersji 1.4

* **Kategoria WIDEO:** Rozpoznaje najpopularniejsze formaty (`.mp4`, `.mov`, `.avi`, `.mkv`).
* **Multi-Color Reports:** W raporcie HTML wideo otrzymało własny kolor (różowy), co pozwala odróżnić je od tysięcy małych zdjęć.
* **Nowe Tryby Skanowania:** Zoptymalizowane zestawy filtrów pod konkretne potrzeby (Multimedia vs Biuro).
* **Deep Visual Clean:** Raport grupowy w formie kart ułatwia szybką decyzję o usunięciu gigabajtowych dubli wideo.

---

## 🚀 Tryby Pracy

1.  **Tylko Zdjęcia (1):** Szybkie czyszczenie galerii zdjęć.
2.  **Multimedia (2):** Zdjęcia + Wideo. Najskuteczniejszy tryb do odzyskiwania największej ilości miejsca (GB).
3.  **Biuro (3):** Zdjęcia + Dokumenty (PDF, Excel, Word).
4.  **Pełny Audyt (4):** Skanowanie absolutnie wszystkiego, co znajduje się na dysku.

---

## 🛠 Szybki Start

1. Uruchom: `python omni_scanner.py`
2. Wybierz tryb **[2]**, aby namierzyć duplikaty filmów i zdjęć.
3. Sprawdź folder `omniscanner_reports` i otwórz raport HTML.
4. Użyj filtra **"⚠️ Giganty"**, aby zobaczyć filmy zajmujące najwięcej miejsca.

---

## 🛡 Bezpieczeństwo i Technologia

* **Fast-Hash:** Nawet filmy o rozmiarze 10GB są analizowane w kilka sekund dzięki technologii sprawdzania skrajnych bloków danych.
* **100% Read-Only:** Skrypt nie posiada modułu usuwania – Twoje dane są bezpieczne, decyzję podejmujesz Ty w oparciu o raport.
